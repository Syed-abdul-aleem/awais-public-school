# User Guide
- Teacher: Dashboard shows assigned work, mark Attendance (Present/Absent/Late/Leave), add Diary & Homework, enter Exam marks for your subjects.
- Accountant: Fees page — generate, collect, print receipt, reports at top. Never ask parents to pay outside a receipt number (APS-000001 format).
- Parent: Sign in, see only your children, switch via Dashboard, check Diary, Attendance %, Fee balance & receipts, published Results only.
- Printing: Fee receipt and Report Card have Print buttons — browser Print > Save as PDF works.
